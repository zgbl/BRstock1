# 🚀 智能股票分析平台：分阶段开发计划 (Roadmap)

本文档制定了从“数据采集”到“AI 自动化决策”的渐进式开发路线，重点在于早期实现 MVP（最小可行性产品），快速跑通流程。

---

## 📅 阶段一：MVP 核心基础（数据与可视化）
**目标**：跑通“抓取 -> 存储 -> 展示”的闭环，让用户能在 Web 端看到自己分析的股票。

1.  **数据层固化 (Pipeline)**
    *   [ ] 将目前的 CSV 存储升级为 **SQLite**（初期）或 **TimescaleDB**（后期）。
    *   [ ] 完善抓取脚本，支持断点续传和自动处理除权除息数据。
2.  **后端 API (Analysis API)**
    *   [ ] 使用 **FastAPI** 搭建基础 RESTful 接口。
    *   [ ] 接口 1：获取股票基础 K 线（OHLCV）。
    *   [ ] 接口 2：计算基础技术指标（SMA, MACD, RSI），可使用 `pandas-ta` 库。
3.  **前端可视化 (Frontend)**
    *   [ ] 使用 React + **TradingView Lightweight Charts** 或 ECharts 渲染 5 分钟图表。
    *   [ ] 实现多股票自选列表（Watchlist）。

---

## 📅 阶段二：信号引擎与用户自定义
**目标**：不再只是看图，系统能根据指标通过“规则”给出买卖信号。

1.  **指标引擎增强**
    *   [ ] 支持用户通过 UI 定制参数（例如：将默认的 RSI 14 改为 RSI 9）。
    *   [ ] 实现“信号扫描”：例如扫描当前自选股中哪些正在发生“均线金叉”。
2.  **分布式/高性能计算初步**
    *   [ ] 将计算逻辑从 Web 主程序分离，确保高频计算不影响界面响应。

---

## 📅 阶段三：AI 智能体集成（核心竞争力）
**目标**：引入外部非结构化数据（新闻、政治等），由 AI 给出深度报告。

1.  **外部数据采集**
    *   [ ] 接入新闻 API（如 NewsAPI, Perplexity 或爬虫抓取雪球/财联社公告）。
    *   [ ] 每日宏观政治/行业动态摘要。
2.  **AI 分析报告生成**
    *   [ ] 集成 **LLM (Gemini 1.5 Pro / GPT-4o)**。
    *   [ ] **Prompt Engineering**：将“K 线指标结果 + 最新新闻内容”输入给 AI，输出《每日 AI 投资内参》。
3.  **情绪分析模块**
    *   [ ] 对新闻文本进行情感打分，作为量化模型的额外维度。

---

## 📅 阶段四：回测引擎与决策迭代
**目标**：验证 AI 和规则的有效性，形成“回测 -> 验证 -> 进化”的闭环。

1.  **回测系统开发**
    *   [ ] 编写基于事件的简单回测逻辑：如果在出现 AI “强力买入”信号时入场，历史收益如何？
    *   [ ] 接入 **ATR 动态止损** 等风险控制逻辑。
2.  **可视化绩效展示**
    *   [ ] 绘制收益率曲线、最大回撤、夏普比率图表。
3.  **模型自我迭代**
    *   [ ] 保存 AI 的预测结果，并与实际走势对比。
    *   [ ] 允许用户调整 AI 的“偏好权重”（如：更看重技术面还是更看重新闻面）。

---

## 🏆 第一步：MVP 任务清单 (本周重点)
1.  **数据库选型与迁移**：将抓取到的 `QQQ`, `VOO`, `TSLA` 数据存入本地 SQLite。
2.  **简单的 Flask/FastAPI 接口**：能返回 JSON 格式的 5m 历史记录。
3.  **一个简单的 HTML 页面**：能静态展示这些数据的折线图。

## 一、趋势类指标

### 1. 移动平均线 (Moving Average, MA)

| 类型 | 说明 |
|------|------|
| **SMA** 简单移动平均 | 过去 N 日收盘价的算术平均值 |
| **EMA** 指数移动平均 | 对近期价格赋予更高权重，对价格变化更敏感 |
| **WMA** 加权移动平均 | 权重线性递增，介于 SMA 与 EMA 之间 |

**常用参数：** 5、10、20、50、100、200 日

**交易信号：**
- 短期均线上穿长期均线 → **金叉**（看涨）
- 短期均线下穿长期均线 → **死叉**（看跌）
- 价格在均线之上 → 上升趋势；之下 → 下降趋势

---

### 2. MACD（Moving Average Convergence Divergence）

**构成：**
- **MACD 线** = EMA(12) − EMA(26)
- **信号线（Signal）** = EMA(9) of MACD 线
- **柱状图（Histogram）** = MACD 线 − 信号线

**交易信号：**
- MACD 线上穿信号线 → **买入**
- MACD 线下穿信号线 → **卖出**
- 柱状图由负转正 → 动能转强
- **背离（Divergence）**：价格创新高而 MACD 未创新高 → 顶背离（危险信号）

---

### 3. 抛物线转向指标 (Parabolic SAR)

- 价格在 SAR 点**上方** → 上升趋势，SAR 在价格下方作为止损参考
- 价格在 SAR 点**下方** → 下降趋势，SAR 在价格上方作为止损参考
- SAR 点翻转 → 趋势可能反转

**特点：** 常配合其他趋势指标使用，适合趋势明显时设置追踪止损

---

### 4. 平均方向指数 (ADX / DMI)

**构成：**
- **+DI**（正向指标）、**−DI**（负向指标）
- **ADX**：衡量趋势强度（不分方向）

| ADX 数值 | 意义 |
|----------|------|
| < 20 | 无明显趋势（震荡市） |
| 20–40 | 趋势开始形成 |
| > 40 | 强趋势 |

**交易信号：**
- +DI 上穿 −DI 且 ADX > 20 → 看涨
- −DI 上穿 +DI 且 ADX > 20 → 看跌

---

### 5. 伊奇莫方云图 (Ichimoku Cloud)

**五条线：**
1. **转换线（Tenkan-sen）**：(9日最高+9日最低)/2
2. **基准线（Kijun-sen）**：(26日最高+26日最低)/2
3. **先行带A（Senkou Span A）**：(转换线+基准线)/2，向前推26日
4. **先行带B（Senkou Span B）**：(52日最高+52日最低)/2，向前推26日
5. **迟行带（Chikou Span）**：收盘价向后推26日

**交易信号：**
- 价格在云上方 → 看涨；云下方 → 看跌；云内 → 震荡
- 转换线上穿基准线 → 买入信号
- 云的厚度 → 支撑/阻力强度

## 二、动量 / 摆动类指标

### 6. 相对强弱指数 (RSI)

**公式：** RSI = 100 − [100 ÷ (1 + RS)]，RS = 平均涨幅 ÷ 平均跌幅

**常用参数：** 14 日

| RSI 区间 | 含义 |
|----------|------|
| > 70 | **超买**，价格可能回调 |
| < 30 | **超卖**，价格可能反弹 |
| 50 附近 | 多空平衡区 |

**进阶用法：**
- **顶背离**：价格新高，RSI 未新高 → 上涨动力减弱
- **底背离**：价格新低，RSI 未新低 → 下跌动力减弱

---

### 7. 随机指标 (Stochastic Oscillator, KD)

**构成：**
- **%K**：(当前收盘 − N日最低) ÷ (N日最高 − N日最低) × 100
- **%D**：%K 的 3日 SMA（平滑）

**常用参数：** 14-3-3

| 数值区间 | 含义 |
|----------|------|
| > 80 | 超买区 |
| < 20 | 超卖区 |

**交易信号：**
- %K 上穿 %D（在超卖区）→ **买入**
- %K 下穿 %D（在超买区）→ **卖出**

---

### 8. 威廉姆斯 %R (Williams %R)

- 范围：−100 至 0
- **−20 以上（接近 0）** → 超买
- **−80 以下（接近 −100）** → 超卖
- 与 Stochastic 类似，但刻度相反，对短期顶底更敏感

---

### 9. 动量指标 (Momentum / ROC)

- **Momentum** = 当日收盘 − N 日前收盘
- **ROC**（变化率）= (当日收盘 − N 日前收盘) ÷ N 日前收盘 × 100

**用途：** 衡量价格变化速度，正值 → 上涨动能，负值 → 下跌动能

---

### 10. CCI（商品通道指数）

- **公式：** CCI = (典型价格 − SMA) ÷ (0.015 × 平均绝对偏差)

| CCI 数值 | 含义 |
|----------|------|
| > +100 | 超买 / 强势突破 |
| < −100 | 超卖 / 弱势突破 |
| 0 附近 | 均衡区 |

**特点：** 对短期极端行情敏感，也可用于识别趋势反转

---

## 三、波动率类指标

### 11. 布林带 (Bollinger Bands)

**构成：**
- **中轨（MB）** = 20日 SMA
- **上轨（UB）** = 中轨 + 2 × 标准差
- **下轨（LB）** = 中轨 − 2 × 标准差

**交易信号：**
- 价格触及**上轨** → 可能超买，注意回调
- 价格触及**下轨** → 可能超卖，注意反弹
- **带宽收窄（Squeeze）** → 波动率降低，大行情即将到来
- **带宽扩大** → 趋势加速中

**注意：** 布林带不是固定的支撑/阻力，价格可以沿轨道"走带"

---

### 12. ATR（平均真实波幅）

**True Range** = max(当日高-低, |当日高-昨收|, |当日低-昨收|)
**ATR** = TR 的 N 日 EMA（通常 14 日）

**用途：**
- 衡量市场波动性大小
- 设置止损位：止损 = 入场价 − 2×ATR（多头）
- ATR 突然放大 → 行情可能剧烈波动

---

### 13. 历史波动率 (Historical Volatility, HV)

- 计算过去 N 日收盘收益率的标准差（年化）
- HV 升高 → 市场不确定性上升
- 常与期权定价（隐含波动率 IV）对比使用

---

## 四、成交量类指标

### 14. 成交量 (Volume)

- **价涨量增** → 趋势强劲，**价涨量减** → 趋势减弱（警惕）
- **价跌量增** → 下跌动能强，**价跌量减** → 下跌可能结束
- 重要突破必须有**放量**确认

---

### 15. OBV（能量潮，On-Balance Volume）

- 上涨日：OBV += 当日成交量
- 下跌日：OBV −= 当日成交量

**用途：** 通过成交量流向预判价格方向
- OBV 与价格同向 → 趋势健康
- OBV 与价格背离 → 趋势可能反转

---

### 16. 成交量加权平均价 (VWAP)

- **VWAP** = Σ(成交量 × 典型价格) ÷ Σ成交量
- 常用于日内交易，机构基准价格
- 价格在 VWAP 上方 → 日内偏多；下方 → 日内偏空

---

### 17. 资金流量指标 (MFI，Money Flow Index)

- 结合价格与成交量的"量价版 RSI"
- 范围 0–100
- **> 80** → 超买；**< 20** → 超卖
- 背离信号与 RSI 用法相同，但加入了成交量权重，更可靠

---

### 18. 蔡金资金流 (Chaikin Money Flow, CMF)

- 衡量一段时间内资金流入/流出的强度
- **CMF > 0** → 资金净流入（看涨）
- **CMF < 0** → 资金净流出（看跌）
- 范围：−1 至 +1，通常 ±0.25 以上才有显著意义

---

## 五、支撑 / 阻力 & 形态类

### 19. 枢轴点 (Pivot Points)

**基础枢轴：** PP = (前日高 + 前日低 + 前日收) ÷ 3

| 水平 | 公式 |
|------|------|
| R1（阻力1） | 2 × PP − 前日低 |
| R2（阻力2） | PP + (前日高 − 前日低) |
| S1（支撑1） | 2 × PP − 前日高 |
| S2（支撑2） | PP − (前日高 − 前日低) |

**用途：** 日内交易中的关键价格关注区域

---

### 20. 斐波那契回调 (Fibonacci Retracement)

**关键回调位：** 23.6%、38.2%、50%、61.8%（黄金分割）、78.6%

**用途：**
- 上升趋势中的买入区域（回调支撑）
- 下降趋势中的卖出区域（反弹阻力）
- **61.8%** 是最受关注的黄金回调位

---

### 21. 蜡烛图形态 (Candlestick Patterns)

**单根 K 线形态：**
| 形态 | 信号 |
|------|------|
| 锤子线 (Hammer) | 下跌后底部反转看涨 |
| 射击之星 (Shooting Star) | 上涨后顶部反转看跌 |
| 十字线 (Doji) | 多空平衡，趋势可能转变 |
| 长上影线 | 上方阻力强，卖压重 |
| 长下影线 | 下方支撑强，买盘承接 |

**多根 K 线形态：**
| 形态 | 信号 |
|------|------|
| 吞噬形态 (Engulfing) | 上涨/下跌趋势反转 |
| 早晨之星 / 黄昏之星 | 底部/顶部反转 |
| 三白兵 / 三乌鸦 | 强势上涨/下跌趋势延续 |
| 孕线 (Harami) | 趋势可能停歇或反转 |

## 六、综合 / 情绪类

### 22. 恐慌与贪婪指数 (Fear & Greed Index)

- 由 CNN 等机构发布，综合多项指标（波动率、价格动量、市场广度等）
- **0–25** → 极度恐慌（潜在买入机会）
- **75–100** → 极度贪婪（潜在风险区域）

---

### 23. 市场宽度指标 (Market Breadth)

- **涨跌线（A/D Line）**：每日上涨股票数 − 下跌股票数的累计值
- **涨跌比率（A/D Ratio）**：上涨数 ÷ 下跌数
- A/D 线与指数同向上涨 → 市场健康；背离 → 注意风险

---

### 24. VIX（波动率指数 / 恐慌指数）

- 衡量标普500期权的**隐含波动率**，代表市场对未来30天波动的预期
- **VIX < 15** → 市场平静，可能自满
- **VIX 20–30** → 市场不安
- **VIX > 30** → 市场恐慌（历史上常为底部区域附近）

## 使用建议

> ⚠️ **单一指标不可靠**，建议多指标组合使用，互相验证。

**经典组合方案：**

| 策略 | 推荐组合 |
|------|----------|
| 趋势跟踪 | EMA 均线 + MACD + ADX |
| 震荡区间 | RSI + KD + 布林带 |
| 突破交易 | 布林带 Squeeze + ATR + 成交量 |
| 反转捕捉 | RSI 背离 + 蜡烛图形态 + 支撑位 |
| 日内交易 | VWAP + 枢轴点 + 成交量 |
| 风险管理 | ATR 止损 + 仓位控制 |

# 智能股票技术分析与回测平台 - 系统设计文档

> **项目名称**: 智能股票分析与决策验证平台 (AI-Driven Stock Analysis & Backtesting Platform)
> **文档版本**: v1.0
> **更新日期**: 2026-04-19

---

## 1. 项目概述
本项目旨在构建一个集股票数据采集、多样化技术指标分析、AI 辅助研报生成、定制化交易决策模型及历史回测引擎于一体的综合性金融分析 Web 平台。系统不仅能为普通用户提供直观的数据可视化，更允许高级用户自定义模型参数并进行历史回测验证，从而实现投资策略的闭环迭代。

---

## 3. 核心功能模块详细设计

### 3.1 股票数据管道 (Data Pipeline & Storage)
*   **功能需求**：从全网自动下载和更新股票的历史交易数据、实时行情、以及基本面、新闻公告等非结构化数据。
*   **设计实现**：
    *   **定时任务 (Cron/Celery)**：每天盘后定时拉取数据。
    *   **在线数据库策略**：
        *   **时序数据库 (Time-Series DB如 TimescaleDB / InfluxDB)**：专用于存储海量、高频的股票 K 线数据（开、高、低、收、量）。
        *   **关系型数据库 (PostgreSQL / MySQL)**：存储用户账户、自选股列表、模型配置参数等结构化数据。
        *   **文本/向量数据库 (MongoDB / Milvus)**：存储新闻、公告、政策研究报告，便于后续 AI 进行 NLP 分析和 RAG（检索增强生成）。

### 3.2 分布式技术分析API计算 (Technical Analysis Server)
*   **功能需求**：提供各类技术指标（如前面总结的均线、MACD、RSI、布林带等）的计算服务。
*   **设计实现**：
    *   **微服务架构**：不同的技术指标可以拆分到不同的计算节点或 Serverless 函数中。这种设计不仅解耦了计算逻辑，还可以针对计算密集型指标分配更多的算力。
    *   请求时，前端输入股票代码及时间范围，计算引擎从时序数据库拉取原始数据，实时计算（或定期预计算并缓存 Redis）出指标序列返回。

### 3.3 Web前端可视化分析 (Frontend Visualization)
*   **功能需求**：在网页端直观展现 K 线图及各类技术指标，允许用户交互操作。
*   **设计实现**：
    *   利用高级金融图表库（如 TradingView Lightweight Charts 或 Apache ECharts）。
    *   **图表叠加与分屏**：主图展示 K 线及趋势型指标（均线、布林带），副图展示动量或成交量指标（MACD、RSI）。

### 3.4 个性化定制与自选股池 (User Customization)
*   **功能需求**：用户可定制自己的股票池（Watchlist），以及特定的技术指标监控条件。
*   **设计实现**：
    *   建立用户偏好模型。用户可以选择订阅"当 AAPL 的 RSI 超卖且 MACD 金叉时通知我"。
    *   后端基于用户的定制参数，实时或盘后扫描全市场，触发相应规则。

### 3.5 多模态 AI 辅助分析与决策 (AI Analyst & Decision Engine)
*   **功能需求**：整合量价数据与外部文本信息，输出自然语言报告及买卖操作建议。
*   **设计实现**：
    *   **结构化输入**：输入当天的时序数据和核心技术指标数组。
    *   **非结构化输入**：抓取近期的公司公告、行业新闻、宏观政策（政治形势等），使用大模型（LLM）进行情感分析（Sentiment Analysis）和意图理解。
    *   **决策模型**：可分为两种：
        1.  **LLM 综合研报生成**：基于 Prompt Engineering 和 RAG，生成人类可读的深度分析报告。
        2.  **量化决策模型 (RL/LSTM/XGBoost)**：用户可以调节风险偏好、特征权重（如新闻权重 30%，技术指标 70%），输出具体的仓位建议和买卖点。

### 3.6 回测引擎与闭环迭代系统 (Backtesting & Iteration)
*   **功能需求**：用历史数据模拟运行用户的决策模型，验证收益率并持续优化。
*   **设计实现**：
    *   **事件驱动回测引擎 (Event-Driven Backtester)**：逐日（或逐分钟）重播历史数据，触发 AI 模型或策略逻辑。
    *   **绩效评估**：计算并展示胜率、年化收益率、最大回撤 (Max Drawdown)、夏普比率 (Sharpe Ratio) 等核心量化指标。
    *   **反馈与训练**：如果 AI 是一种深度学习/强化学习模型，系统应允许保存用户每次模拟的结果，使用表现优异的参数重新Fine-tune模型。

## 4. 技术栈推荐选型 (Tech Stack Reference)

| 领域 | 推荐技术栈 | 理由 |
| :--- | :--- | :--- |
| **前端框架** | React / Vue 3 + TypeScript | 组件化程度高，适合复杂的金融数据控制台。 |
| **金融图表** | TradingView Lightweight Charts | 提供高度专业、流畅的 K 线渲染效果。 |
| **后端主服务** | Python (FastAPI 或 Django) | Python 是数据科学和量化交易的绝对主力，集成 AI 最方便。接口响应快。 |
| **核心数据库** | TimescaleDB (基于 PostgreSQL) | 既保持了 SQL 的易用性，又具备极高的时序数据读写与压缩性能。 |
| **AI 框架** | LangChain / LlamaIndex / PyTorch | 结合大模型 RAG 服务处理文本新闻，PyTorch 训练深度时序预测模型。 |
| **缓存/消息队列** | Redis / RabbitMQ | 用于缓存热点行情数据、调度数据爬取任务和回测异步任务。 |

## 5. 项目开发路线图 (Roadmap)

此项目体量庞大，建议分阶段敏捷开发：

*   **Phase 1：基础设施建设 (MVP)**
    *   搭建数据库，实现定时下载 Yahoo Finance/Tushare 的股票数据并存储。
    *   构建后端 API，能输出基础的 K 线数据和几项简单技术指标（如 SMA, MACD）。
    *   开发前端界面，完成基础行情的可视化。
*   **Phase 2：高级分析与个性化**
    *   扩展技术指标计算 API，实现微服务架构。
    *   加入用户系统，实现自选股功能及指标参数调优界面。
*   **Phase 3：AI 分析师上线**
    *   整合爬虫爬取相关新闻。
    *   接入大模型 API，基于每日技术形态和新闻综合输出 "AI 股票分析日报"。
*   **Phase 4：回测引擎与决策迭代**
    *   开发核心回测引擎，允许用户用历史数据跑模拟交易。
    *   开放多维策略组合让用户调参，形成报告 -> 验证 -> 优化的闭环体验。
